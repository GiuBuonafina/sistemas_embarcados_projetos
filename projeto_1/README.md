# Projeto 1 — GPIO e PWM de Software

Disciplina de **Sistemas Embarcados** — Universidade de Pernambuco (UPE)

**Equipe:** Giulia Buonafina, Maria Luana Rodrigues

## Objetivo

A partir do código de PWM disponibilizado, criar um projeto para controlar a saída GPIO conectada ao LED da placa NUCLEO, ajustando os parâmetros de **frequência** e **duty cycle** para visualizar seus efeitos sobre o brilho/piscar do LED.

## Resultado

| Frequência (Hz) | Duty cycle (%) | O que observar |
| --- | --- | --- |
| 100 | 10 | LED bem fraco, quase apagado, ainda com um leve piscar |
| 100 | 50 | LED em brilho médio e constante, sem conseguir visualizar piscando |
| 100 | 90 | LED forte, com brilho máximo |
| 5 | 50 | Piscar visível, sem dar efeito de brilho |
